# Changelog / Historial

## 1.25 — 2026-10-11

### English

First packaged publication in this repository, including the improvements developed through versions 1.15–1.25:

- Telegram-driven download queue with direct downloads, optional AllDebrid and qBittorrent forwarding.
- Editable/testable connections, right-click paste and guided setup.
- Dark Windows title bars, compact responsive columns, alternating rows and readable sizes.
- Separate Telegram/API ID and group status indicators.
- Local settings and session storage; release packages exclude personal configuration.
- Frozen-EXE restart correction with independent temporary extraction.
- 27 automated tests and compiled startup checks.

### Español

Primera publicación empaquetada en este repositorio, con las mejoras desarrolladas entre las versiones 1.15 y 1.25:

- Cola desde Telegram, descarga directa, AllDebrid opcional y envío de torrents a qBittorrent.
- Conexiones editables/comprobables, pegado con ratón y configuración guiada.
- Barras de Windows oscuras, columnas adaptables, filas alternas y tamaños legibles.
- Indicadores independientes de Telegram/API ID y acceso al grupo.
- Ajustes y sesiones locales; paquetes publicados sin configuración personal.
- Reinicio corregido del EXE con extracción temporal independiente.
- 27 pruebas automáticas y comprobaciones de arranque del ejecutable.
