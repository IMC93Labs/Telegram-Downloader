# Security / Seguridad

Never post credentials, tokens, API hashes or authenticated Telegram sessions in public issues. If sensitive information is accidentally exposed, revoke/replace the affected credentials through the relevant service.

No publiques contraseñas, tokens, API Hash ni sesiones autenticadas en incidencias públicas. Si se exponen accidentalmente, revoca o sustituye las credenciales afectadas en el servicio correspondiente.

Local credentials are stored unencrypted in the Windows user profile. Review [privacy documentation](docs/PRIVACY.en.md) / [documentación de privacidad](docs/PRIVACY.es.md) before sharing files.

For a security report, use GitHub's private vulnerability reporting if enabled. Otherwise do not include exploitable details or credentials in a public report.
